# qualityd

Local HTTP Quality Studio for **Weavatrix Quality**.

```sh
cargo install qualityd --version 0.1.0-alpha.1
qualityd --repo .
```

Exception-first cockpit over the shared command bus. Alpha / unstable.

Prefer npm `wvq` for the CLI/MCP binaries; use `qualityd` when you want the local Studio HTTP UI.
